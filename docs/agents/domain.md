# Domain docs

This repository has one domain context.

## Before exploring or drafting tickets

- Read `CONTEXT.md` at the repository root for Skipper vocabulary.
- If `docs/adr/` exists, read decisions relevant to the task.
- If a domain document is absent, continue without creating a placeholder.

## Vocabulary

Use the terms and definitions in `CONTEXT.md`, including its synonym guidance.
Follow the definition format and update rules in the root `AGENTS.md`.

## Decisions

If a proposal conflicts with an existing ADR, identify the conflict explicitly.
Create ADRs only for agreed decisions that justify a separate decision record.
